## macOS 原生窗口

真实 Cocoa 窗口运行 `CaliburnMultiScreenApp --auto-close 5`，未设置 software 渲染；程序请求 OpenGL。

- 自动识别为预览模式，两窗首帧均提交。
- 主窗实际内容几何 `(72,70,936,530)`，辅助窗 `(288,487,1080,244)`，窗口 DPR=2。
- 启动诊断通过，五秒自动关闭后状态码为 0。
- 使用 Cocoa 为每个交互场景分别启动独立测试进程：辅助窗独立关闭、退出按钮、主窗原生 close() 路径全部通过；各场景同时检查 Esc 无动作。
- 原生交互测试报告保存在 `build/debug/multiscreen-cocoa-{auxiliary,button,primary}.txt`；离屏通过不作为原生窗口行为依据。

原生运行出现 macOS 输入法 mach-port 诊断和本机缺少 Noto Sans CJK SC 的字体回退提示，不影响首帧和退出检查；麒麟继续使用指定中文字体。
