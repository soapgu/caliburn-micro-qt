# 窗口管理与 Conductor 接口化验收记录

2026-10-13，macOS arm64 / Qt 6.8.3。本次按精简方案实现 QObject 类型边界与可选生命周期接口。

## 实现与迁移

- 普通窗口继续接受 typed QVariant 并借用 QObject；弹窗消费 unique_ptr<QObject>，currentDialog 返回 QObject*；根工厂持有 QObject。
- IParent、IConductor、关闭策略、活动项与扩展点统一使用 QObject；模板默认 T = QObject，基类、IConductor 与 QML 属性入口均检查模板实际类型。
- IDeactivate 新增带 QObject 上下文的尝试/完成通知订阅，Screen 复用现有信号。按尝试通知避免重复关闭，按 close=true 完成通知反向关窗。
- Screen.closeRequested 保留条件连接，不新增 ICloseRequestSource 或 IClose。普通 QObject 通过窗口操作关闭时返回空结果。
- 保留原有所有权、逻辑 Parent、生命周期顺序、关闭策略、弹窗结果、退出顺序与焦点行为。公开 IID 和消费端签名同步迁移，详见 [接口化迁移](../接口化迁移.md)。

## 原生示例交互

通过桌面 UI 操作本次构建的 CaliburnExampleApp，验证：

1. 点击增加两次，计数显示 2，重置按钮可用。
2. 重置弹窗默认聚焦取消；Escape 关闭弹窗，计数保持 2。
3. 重新打开弹窗并确认，计数归零。
4. 进入详情后 Home 停用、Detail 激活；返回确认选择取消，详情继续显示。
5. 在详情页关闭主窗口，出现离开详情守卫；确认后应用退出，应用清单显示 isRunning=false。

本机验收不覆盖麒麟和外部消费工程。未引入 View 关联、View 缓存、context、多窗口或生命周期时序调整。
