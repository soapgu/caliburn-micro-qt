## 交付

- Qt 分类日志直接作为记录接口，不引入 ILog/LogManager，不要求日志接口对齐 CM。框架不依赖 spdlog，也不接管全局消息处理器。
- example 增加独立日志支持目标，现由 FetchContent 获取固定 spdlog v1.17.0；同步输出控制台及轮转文件，Qt/QML 自身诊断进入同一出口。
- `caliburn.example` 在 Debug 默认启用 Debug 及以上，其余配置默认 Info 及以上；保留类/函数、文件行号、线程、Qt 原始级别和原生过滤/格式覆盖。
- 增加启动、退出与计数操作演示，以及文件不可用降级、处理器恢复、多线程安全和 Fatal 刷新。框架流程日志仍由 6B 实施。

接口、路径和使用边界见 [日志接入](../日志接入.md)。

  -DCMAKE_BUILD_TYPE=Release -DCALIBURN_BUILD_EXAMPLE=OFF \

  -DCALIBURN_BUILD_EXAMPLE=OFF -DCALIBURN_BUILD_TESTS=OFF
