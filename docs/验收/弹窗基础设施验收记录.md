# 弹窗基础设施验收记录

> 历史验收记录。2026-10-11 已将 attachToWindow / detachFromWindow 收为 private，取消外部窗口手动接入；本文涉及公开挂载、解除挂载或独立引擎销毁的场景仅描述当时实现。当前调用方式见 [WindowManager](../WindowManager.md)。


日期：2026-10-09。环境：macOS arm64、Qt 6.8.3、C++17，使用既有 macos-local 预设，未修改个人构建配置。

## 交付结果

Bootstrapper 在 Configure 前创建窗口服务，根工厂统一接收同一 shared_ptr<IWindowManager>；根窗口加载后自动挂载标准 DialogHost。Shell 不再声明宿主或暴露窗口服务，AppBootstrapper 不再登记框架确认视图。应用显式视图映射优先于框架默认映射。

RootViewOptions 保留为空结构，由 DisplayRootViewFor<T>(options = {}) 接收，预留未来根窗口设置扩展；当前不影响行为。根工厂直接保存到注册表，创建 VM 后以具体 T* 注入 QML，Bootstrapper 始终自动挂载宿主。独立 QML 窗口可调用 WindowManager::attachToWindow / detachFromWindow；服务或目标窗口已有宿主时拒绝重复挂载，不替换手动宿主。

## 执行与结果

构建和 Qt 测试在沙箱外执行；沙箱内首次配置触发了已知的 Qt neon 检测失败，沙箱外重新配置成功。

```sh
cmake --preset macos-local -B /private/tmp/cmqt-dialog-infra-build
cmake --build /private/tmp/cmqt-dialog-infra-build --target all all_qmllint -j 4
ctest --test-dir /private/tmp/cmqt-dialog-infra-build --output-on-failure -j 4
cmake --preset macos-local -B /private/tmp/cmqt-dialog-infra-framework-only \
    -DCALIBURN_BUILD_EXAMPLE=OFF -DCALIBURN_BUILD_TESTS=OFF
cmake --build /private/tmp/cmqt-dialog-infra-framework-only --target all all_qmllint -j 4
```

新增 Bootstrapper 场景验证统一工厂签名、窗口服务注入一致性、显式传入空选项、空工厂拒绝及宿主冲突导致启动失败后的清理；同时回归延迟创建、具体类型 QML 注入和空 VM。框架弹窗测试验证默认映射、应用覆盖、无效覆盖不回退、冻结限制、重复挂载、目标窗口冲突、非法线程、业务布局隔离与尺寸跟随。

生命周期测试分别销毁窗口、独立 QML 引擎、服务和请求者，并主动解除挂载，验证 Future 完成、忙状态清理及 View 先于 VM 销毁。既有弹窗测试继续验证接受、取消、Escape、Tab 循环、模态输入隔离、焦点恢复、自定义弹窗及页面切换。

QML 测试使用 offscreen/software 和 Basic 样式。本轮未进行真实窗口人工操作或麒麟验证。故意非法的既有 QML 夹具和静态插件重复链接会产生预期诊断，不影响通过结果。根 VM 激活仍早于窗口加载，激活钩子中立即弹窗不在本次支持范围内。
