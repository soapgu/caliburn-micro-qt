# 6B 框架层日志验收记录

2026-10-12，macOS 27.0 arm64 / Qt 6.8.3 / C++17。6B 已实现并完成本机自动检查及真实 Cocoa 窗口验收。麒麟、外部消费工程和远程 CI 尚未验证。

## 交付与边界

- 框架新增 `caliburn.microqt.core/lifecycle/conductor/view/window/bootstrapper` 六个内部分类，示例继续使用 `caliburn.example`。框架只依赖 Qt，不接管消息处理器、不依赖 spdlog 或 Boost.DI。
- 关键过程与结果使用 Info，细节使用 Debug；正常取消和关闭许可拒绝使用 Info，既有警告和错误沿用 Warning/Critical。Debug 默认启用 Debug，其余配置默认 Info，支持 Qt 原生规则和格式覆盖。
- 生命周期对齐 CM 3.2.0：激活和停用日志位于业务钩子之前，关闭完成日志位于关闭钩子及停用通知正常返回之后。异常保持原传播契约；失败不报告完成，幂等选择不重复报告活动项切换。
- 视图注册、冻结、映射查询、ViewHost 装配与失败进入 `.view` 分类；ViewHost 的三个报告方法只承担日志输出。失败记录模型及可用的请求 URL。
- 导航和关闭许可、普通窗口与弹窗、焦点恢复、启动退出及资源清理已接入分类日志。跨回调使用对象标识快照与弱引用，销毁后的守卫结果不访问失效对象。
- 项目维护的运行时日志、异常诊断、QML 不可创建提示以及输出组件降级提示使用英文；界面继续中文。Qt/QML 与第三方组件自身诊断和调用方提供的消息保留原文，Unicode 输出测试继续保留。

CM 对照依据和分类用法见 [日志接入](../日志接入.md)。本阶段增加的 Qt 流程日志不引入约定绑定、视图缓存、公共日志服务或异步日志队列。

主要命令在仓库根目录执行：

```sh
cmake --build --preset macos-local -j 4
ctest --preset macos-local --output-on-failure -j 4
cmake --build --preset macos-local --target all_qmllint -j 4

cmake --preset macos-local -B /private/tmp/cmqt-6b-release \
  -DCMAKE_BUILD_TYPE=Release -DCALIBURN_BUILD_EXAMPLE=OFF \
  -DFETCHCONTENT_SOURCE_DIR_SPDLOG="$PWD/build/debug/_deps/spdlog-src" \
  -DFETCHCONTENT_SOURCE_DIR_BOOST_DI="$PWD/build/debug/_deps/boost_di-src"
cmake --build /private/tmp/cmqt-6b-release \
  --target CaliburnLoggingTests CaliburnFrameworkLoggingTests -j 4
ctest --test-dir /private/tmp/cmqt-6b-release \
  -R '^(logging|framework_logging)$' --output-on-failure

cmake --preset macos-local -B /private/tmp/cmqt-6b-framework-only \
  -DCALIBURN_BUILD_EXAMPLE=OFF -DCALIBURN_BUILD_TESTS=OFF \
  -DFETCHCONTENT_FULLY_DISCONNECTED=ON
cmake --build /private/tmp/cmqt-6b-framework-only --target all all_qmllint -j 4
```

## 真实 Cocoa 窗口

通过原生 UI 操作日常 Debug 示例，最终源码构建后再次完整验证：

1. 启动显示计数 0，Shell 和 Home 已激活。
2. 点击“增加”和“加 2”，显示计数 3。
3. 打开重置确认窗口并确认，计数归零，重置按钮禁用。
4. 打开详情页，Home 停用，Detail 激活。
5. 点击主窗口关闭，出现离开详情确认；取消后主窗口和详情页保留。
6. 点击“返回首页”并确认，Detail 关闭，Home 重新激活。
7. 关闭首页主窗口，应用正常退出；文件记录 `Bootstrapper exited; exit code: 0` 和 `Application exited; exit code: 0`。

实际文件为 `~/Library/Application Support/CaliburnMicroQt/CaliburnExampleApp/logs/CaliburnExampleApp.log`。最终本次运行片段保存在 `/private/tmp/cmqt-6b-cocoa-final.log`，包含启动、计数、重置、页面切换、弹窗结果、关闭许可拒绝与最终退出；日志正文全部英文，界面文案保持中文。
