# 5B Detail 退出确认与 Conductor 关闭守卫验收记录

2026-10-09，基于 `abeb44c` 实施。5B 已实现并完成 macOS arm64 全量构建、自动检查、Cocoa 集成及实际窗口交互验收；麒麟和外部消费工程待验证。历史验收记录保持原样，未暂存、提交或推送。

## 本轮交付

- 新增纯 C++ IGuardClose、ICloseStrategy 与 DefaultCloseStrategy。Screen 默认立即同意；默认策略依次询问全部成员，遇到拒绝仍继续，最终全体同意才允许关闭，不提供部分关闭选项。
- activateItem、deactivateItem、closeItem、tryClose 及模板包装统一返回 void，addItem 保留 bool；IConductor IID 更新为 `/2.0`。closeItem 委托虚调用 deactivateItem(item, true)，全部仓内调用方和测试完成迁移。
- activationProcessed 保留；Screen 新增 attemptingDeactivation 和 deactivated，分别在有效生命周期执行前和钩子正常完成后发送。拒绝和失效不伪造关闭完成通知，直接生命周期仍同步执行。
- 单项替换及成员停用/关闭检查守卫；集合仅成员关闭检查。父级普通停用仍同步传播，canClose 检查全部持有成员，包含单项留存项和嵌套 Conductor。
- 请求独立，无全局忙锁或队列；固定请求开始时的策略，使用 QPointer、成员身份和生命周期/选择代次验证提交。重复回调忽略，重复关闭最多提交一次；管理者或参与对象失效取消请求，迟到许可不能修改恢复后的页面。
- 候选通过基础校验后移入请求暂存，许可通过才接管为成员；拒绝、取消或过期时回收，候选提前销毁解除暂存所有权。守卫/策略异常按拒绝诊断；同步生命周期异常传播，延后执行异常在回调边界诊断并终止，不回滚已提交状态。
- Detail 注入现有 IWindowManager，goBack 仅在活动时调用 tryClose。“返回首页”确认仅 true 允许关闭；取消、Escape、空结果、窗口忙和展示失败均拒绝。停用或销毁取消自己的弹窗，非活动受管 Detail 仍接受显式许可检查。
- 集合新增 prepareCloseItem；Shell 在许可通过后补齐缺失 Home，取消不补建，工厂失败保留 Detail。Home VM 常驻、共享计数、View 每次新建，以及先卸载 View 后延迟删除 VM 的顺序继续保持。

当前契约和 Qt 适配差异见 [关闭守卫](../关闭守卫.md)、[Conductor](../Conductor.md) 与 [ScreenViewModel](../ScreenViewModel.md)。请求返回类型和 IConductor IID 为破坏性变更，外部消费工程需同步迁移。

## 环境与命令

macOS arm64、Qt 6.8.3、C++17，使用现有 macos-local 预设和独立构建目录，未修改本机预设。沙箱内 Qt 工具受 neon 特征检测限制，最终 Qt 构建和测试均在沙箱外执行。

```sh
cmake --preset macos-local -B /private/tmp/cmqt-5b-build
cmake --build /private/tmp/cmqt-5b-build -j 4
ctest --test-dir /private/tmp/cmqt-5b-build --output-on-failure -j 4
cmake --build /private/tmp/cmqt-5b-build --target all_qmllint -j 4
cmake --preset macos-local -B /private/tmp/cmqt-5b-framework-only \
  -DCALIBURN_BUILD_EXAMPLE=OFF -DCALIBURN_BUILD_TESTS=OFF
cmake --build /private/tmp/cmqt-5b-framework-only --target all all_qmllint -j 4
QT_QPA_PLATFORM=cocoa QT_QUICK_BACKEND=software /private/tmp/cmqt-5b-build/tests/CaliburnDialogTests
QT_QPA_PLATFORM=cocoa QT_QUICK_BACKEND=software /private/tmp/cmqt-5b-build/tests/CaliburnQmlTests
```

## 实际窗口交互

使用最终构建 `/private/tmp/cmqt-5b-build/bin/CaliburnExampleApp.app` 进行桌面 UI 操作并观察状态：

- 初始计数 0，加 2 后进入 Detail 显示共享计数 2；Home 保持已初始化、未激活。
- 点击返回出现“返回首页／确定离开详情并返回首页吗？”确认，默认焦点为取消。弹窗期间数字键 2 不改变计数，Return 在取消按钮上关闭弹窗，Detail 保持活动。
- Escape 关闭确认并保留 Detail；再次请求，Tab 到确认后 Return 接受，返回 Home，计数仍为 2，Detail 显示无页面。
- 返回后页面数字键 2 可增加到 4，文本框输入 2 只修改文本。Home 重置经确认后归零，并恢复原输入焦点。
- 再次进入 Detail 显示 0，鼠标接受后返回 Home，重新创建的 Home View 文本框为空。
- 最终构建再次复核 Escape 拒绝和鼠标接受，返回后共享计数仍为 2；正常关闭实际窗口。
