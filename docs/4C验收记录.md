# 4C 验收记录：Collection.OneActive 与 Detail 导航

2026-10-07，基于提交 `c126a08` 实施。4C 源码、自动检查、Cocoa 与实际窗口验收完成，第四批本机验收完成；银河麒麟和外部消费工程仍待验证。未暂存、提交或推送，历史验收记录保持原样。

## 本轮交付

- 新增独立集合型元对象基类与泛型层，可通过 `Conductor<T>::Collection::OneActive` 使用；单项 Conductor 实现和契约不变，仅增加集合型别名。
- 提供只读集合快照、新项接管、已有成员选择、清空选择和成员关闭。切换保留旧项；关闭当前项优先选前一项，没有前一项选后一项；意外销毁只移除和清空、不自动导航。
- Shell 注入 Home/Detail 两个工厂，home/detail 从集合查找。Home VM 导航期间常驻，Detail 按需创建、返回后关闭移除并延迟释放；两页使用同一计数服务。
- Detail 只读展示计数。ViewHost 沿用原契约，导航每次新建 View；返回 Home 保留 VM 身份、初始化次数和计数，文本和焦点按新 View 初始化。
- View 保留机制仅记录在 [后续版本 ToDoList](后续版本ToDoList.md)，未加入缓存、异步确认或关闭守卫。

## 真实窗口操作

使用本轮构建产物，通过原生窗口操作及截图检查布局：

| 操作 | 观察结果 |
| --- | --- |
| 启动 Home | Shell/Home 均初始化且活动，Detail 无页面，计数 0，返回禁用。 |
| 点击加 2，再在文本框输入 2 | 计数 2，文本为 2，输入未被页面计数处理。 |
| 查看详情 | Home 已初始化但非活动；Detail 已初始化且活动，显示共享计数 2；进入禁用、返回可用。 |
| 返回首页 | Home 恢复活动，Detail 无页面；计数仍为 2，文本框恢复空值。 |
| 直接按数字键 2 | 返回后的页面焦点有效，计数变为 4，加 2 禁用。 |
| 重置，Tab 后按空格 | 增加按钮获得焦点并执行，计数 1。 |
| 数字键 2 两次，再进入 Detail | 详情显示共享计数 5；截图确认生命周期文字、导航按钮及只读详情布局。 |
| 从 Detail 关闭窗口 | 正常关闭；另从 /private/tmp 直接启动二进制，进入 Detail 再关闭，进程退出码 0。 |

VM 身份、初始化次数、View 身份、Detail 延迟删除和销毁先后由 C++/QML 自动测试验证，人工观察仅记录窗口可见行为。Shift+Tab、修饰键及自动重复过滤由既有自动测试回归，未另做实体长按计时。
