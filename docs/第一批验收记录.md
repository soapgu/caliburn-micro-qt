## 5. 默认目标与可选守卫调整（2026-10-05）

ActionButton 默认查找最近 View 的 viewModel，父链未找到时使用所属窗口；最近 View 的空 VM 是边界，显式 target（含 null）覆盖默认绑定。Shell 两个按钮已移除重复目标配置。独立 ActionBinding 仍显式提供目标，rebuild 的配置更新方式保持不变。

合法操作缺少 canXxx 时默认允许；动态守卫需要可读 bool 与 NOTIFY，恒定守卫支持 CONSTANT；非法守卫继续诊断并禁用。移除目标 destroyed 监听，保留 QPointer 和执行前复核，正常装配要求先销毁 View 与绑定、再释放其目标 VM。意外先销毁 VM 不保证立即通知或更新 enabled；再次执行或显式清空目标时禁用。

本次回归包含构建、CTest 的 core/qml 两组测试和 all_qmllint（无 QML 警告）。新增测试覆盖无守卫、恒定 true/false、不可读与非法守卫、守卫配置切换、销毁后的安全执行与显式清空；QML 覆盖窗口默认目标、嵌套 View 边界、显式目标/null、VM 替换、按钮和中间容器重新挂载、跨窗口迁移，以及原计数按钮事件。真实 example 手工操作与 Cocoa 验收沿用上文初始批次记录，本次未重复执行。

Qt 工具在沙箱内检测 arm64 neon 特性失败，本次构建与 Qt 检查在沙箱外执行。不可读守卫的测试替身故意省略 READ，moc 会提示该属性无效；这是非法契约用例，测试验证框架拒绝执行。链接器原有重复库提示仍存在。

## 6. 普通按钮约定装配与附加属性（2026-10-05）

删除 ActionButton，新增 ViewBinding 与 CmAction 两个 C++ 附加类型，保留 ActionBinding 执行核心。Shell 根窗口设置 ViewBinding.model，两个普通 Button 的 objectName 分别为 increment/reset，无需 actionName、专用按钮基类或业务 onClicked。已从模块与资源列表移除 ActionButton.qml。

CmAction.method/target 显式覆盖方法或目标，目标覆盖不改变 objectName 方法约定；显式 null 禁用，赋 undefined 恢复默认。子 View 的 viewModel 或独立 ViewBinding 是作用域边界，空 VM 不回退。框架观察视觉子项与名称变化，处理 Loader/Repeater、容器重新挂载和跨窗口迁移，重复扫描不重复连接。已使用原生 Qt action 的按钮跳过约定装配；已绑定按钮的 enabled 由框架管理，退出接线时恢复原值或表达式。

本次构建、core/qml 两组 CTest 和 all_qmllint 回归覆盖普通/派生按钮、按名匹配、附加方法与单独目标覆盖、显式 null 与恢复默认、VM 替换和同一事件轮目标更新、动态子项及销毁、单次点击、原生 Action 保留及解除后的装配、原有 enabled 表达式恢复，以及原 Shell 计数和守卫边界。关闭示例与测试后的仅框架构建也已通过。Qt 工具继续在沙箱外执行；本次未重复手工窗口操作或 Cocoa 测试，未执行 Git 提交。

## 7. 1.0 移除动作层，改用手写绑定（2026-10-05）

第 1–6 节是先前阶段历史；其中的动作层接口、约定装配和相应测试已不属于当前 1.0。当前框架只提供 ViewModelBase 与类型化 setAndNotify，按钮在用户 View 中显式绑定 enabled 并通过 onClicked 直接调用 VM。objectName 仅用于对象标识与测试，canIncrement/canReset 仍是 VM 的业务属性，increment/reset 自身保留范围检查。

已删除 ActionBinding、CmAction/CmActionAttached、ViewBinding/ViewBindingAttached 以及 ButtonActionConnection.qml，清理源码、资源和注册列表；没有兼容包装或替代执行组件。框架只链接 Qt Core/Qml，示例与 QML 测试另使用 Quick/QuickControls2。旧动作层测试替身与专用测试已删除，保留通知、业务边界、类型注入、所有权及真实按钮事件测试，并增加实际 ShellView 的 VM 替换回归。
