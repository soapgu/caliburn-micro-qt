# 5A 通用模态弹窗与 Home 重置确认验收记录

2026-10-08，基于 `cbb43fa` 实施。5A 已实现并完成 macOS arm64 构建、自动检查、Cocoa 集成及实际窗口交互验收；麒麟待验证。5B 的 Detail 退出确认、回调守卫和请求接口迁移仍为规划中、未实施、未验证。历史验收记录保持原样，未暂存、提交或推送。

## 本轮交付

- IWindowManager 为不可由 QML 创建的抽象 QObject 服务，WindowManager 提供单请求通用模态展示；入口接受普通自定义 ScreenViewModel，不要求确认专用基类。
- showDialogAsync 按值消费 unique_ptr，返回 QFuture<std::optional<bool>>：接受 true、明确取消 false、无决定关闭空值；无效参数、忙、宿主不可用、映射或加载失败及生命周期异常通过 Future 交付。
- 确认文案值类型 ConfirmationRequest、ConfirmActionViewModel/View 和 DialogHost 已加入框架。DialogHost 复用 ViewRegistry/ViewHost，Item 型 Popup 隔离输入，外部点击不关闭，支持 Tab/Shift+Tab、Return/Enter/Space、Escape 和有效焦点恢复。
- 请求标识与 QPointer 处理旧通知、重复完成和对象失效；关闭中仍 busy，先卸载 View，再关闭 VM、deleteLater 并完成 Promise。请求者、VM、宿主或管理者失效不会留下悬挂请求。
- 每个 buildShell 创建独立 shared_ptr 窗口服务，注入 Shell/Home；确认 VM 借用服务，不形成引用环。Home.reset 只有接受且仍活动时才重置；普通停用/关闭取消请求，代次标识阻止过期结果影响恢复后的页面。
- AppBootstrapper 在冻结前登记确认映射；框架新增 QuickControls2 依赖。Screen、Conductor、Detail.goBack 与 BootstrapperBase 的现有协议和算法未改变。

接口、所有权及 CM 3.2 的 Qt 适配差异见 [WindowManager 专题](WindowManager.md)。

## 环境与命令

macOS arm64、Qt 6.8.3、C++17，使用现有 macos-local 预设，未修改本机预设。沙箱内 QML 扫描工具因 neon 特征检测受限退出；最终构建及 Qt 测试均在沙箱外执行。

```sh
cmake --preset macos-local -B /private/tmp/cmqt-5a-build
cmake --build /private/tmp/cmqt-5a-build -j 4
ctest --test-dir /private/tmp/cmqt-5a-build --output-on-failure -j 4
cmake --build /private/tmp/cmqt-5a-build --target all_qmllint -j 4
cmake --preset macos-local -B /private/tmp/cmqt-5a-framework-only \
  -DCALIBURN_BUILD_EXAMPLE=OFF -DCALIBURN_BUILD_TESTS=OFF
cmake --build /private/tmp/cmqt-5a-framework-only --target all all_qmllint -j 4
QT_QPA_PLATFORM=cocoa QT_QUICK_BACKEND=software /private/tmp/cmqt-5a-build/tests/CaliburnDialogTests
QT_QPA_PLATFORM=cocoa QT_QUICK_BACKEND=software /private/tmp/cmqt-5a-build/tests/CaliburnQmlTests
```

## 实际窗口交互

使用最终构建 `/private/tmp/cmqt-5a-build/bin/CaliburnExampleApp.app`，通过桌面 UI 实际操作并观察结果：

- 初始 0，加 2 后显示 2；点击重置出现模态确认框，文案正确，默认焦点为取消。
- 弹窗期间数字键 2 不改变计数，Tab 在确认/取消之间切换；Return 在取消按钮上关闭弹窗并保留 2。
- 再次打开后 Tab 到确认、Return 接受，计数变为 0；关闭后数字键 2 可再次增加，页面焦点恢复。
- Escape 关闭弹窗并保留计数；Space 取消已在窗口验证，鼠标接受及外部点击隔离另有 Cocoa 集成覆盖。
- 文本框输入 2 只修改文本，不改变计数；进入 Detail 显示共享计数 2，返回 Home 保留计数，未加入 5B 的退出确认。
- 正常关闭实际窗口并退出应用。原生窗口检查没有替代麒麟验证。

## 边界
