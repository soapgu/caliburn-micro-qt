## 实现范围

- 示例新增 CounterService，唯一计数初始 0、范围 0～5，先检查剩余额度；非法输入、同值操作不通知，不注册 QML 类型。
- Home 显式注入非空 shared_ptr 服务，直接读计数，委托操作。构造初始化守卫缓存；服务变化时先更新缓存，再发送计数及实际变化的守卫通知。
- Shell 继承 Conductor<ScreenViewModel>，注入可重复调用的 Home 工厂。构造选择未初始化页面，只重写 onActivate 处理空项重建。home 属性投影 activeItem，宿主绑定 activeItem。
- buildShell 每次创建独立服务。工厂只捕获服务，每次使用局部 DI 注入器创建页面；页面由 Conductor 父树管理，服务由 shared_ptr 管理。DI 仍是装配库私有依赖。
- 普通停用保留页面；关闭清空并延迟回收，重建保留计数；意外销毁只清空，下次激活才重建。不修改框架核心契约，不增加 Detail 或集合型占位类型。

## 环境与命令

macOS 27.0.1 arm64、Qt 6.8.3、AppleClang 21.0.0.21000334、CMake 3.30.5、Ninja、C++17。使用现有 macos-local 预设，Qt kit 为 `/Users/guhui/Qt/6.8.3/macos`，不改个人或公共预设。构建与运行在沙箱外执行。

```sh
cmake --preset macos-local -B /private/tmp/cmqt-4b-build
cmake --build /private/tmp/cmqt-4b-build -j 4
ctest --test-dir /private/tmp/cmqt-4b-build --output-on-failure
cmake --build /private/tmp/cmqt-4b-build --target all_qmllint -j 4
cmake --preset macos-local -B /private/tmp/cmqt-4b-framework-only \
  -DCALIBURN_BUILD_EXAMPLE=OFF -DCALIBURN_BUILD_TESTS=OFF
cmake --build /private/tmp/cmqt-4b-framework-only --target all all_qmllint -j 4
cd /private/tmp
QT_QPA_PLATFORM=cocoa /private/tmp/cmqt-4b-build/tests/CaliburnQmlTests
```

## 实际窗口回归

使用本轮生成的 CaliburnExampleApp.app，观察窗口、控件状态与截图并操作：

| 操作 | 实际结果 |
| --- | --- |
| 启动 | Shell/Home 均初始化且活动，计数 0，重置禁用。 |
